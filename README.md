Twilight Compass

A configurable horizontal compass HUD for Twilight Princess on Dusklight.

- Horizontal compass rotates to show which direction the camera is facing in game.
- Dungeon Chest Markers indicate the direction of a dungeon's chests, only visible after obtaining the dungeon's compass.
- Display the name of your current location.
- Hides the mini-map by default so the compass replaces it. Minimap can be toggled back on if you still wish to keep it.
- Compass and Location Name are customizable in position, opacity, and size.
